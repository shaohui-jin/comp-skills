# Changelog

本文件随 VSIX 发布到 Open VSX / Cursor 扩展市场，用于展示版本变更记录。

| 版本     | 日期 | 变更项 |
|--------|------|--------|
| 0.1.0  | 2026-08-19 | 1. **首版发布**：Vue 组件依赖分析系统，支持依赖图、循环依赖检测、无用组件识别、扇入扇出统计、分层/越层检查<br>2. **可视化重构**：dagre 分层布局 + 卡片节点，节点直接展示组件名、扇入/扇出、行数、状态（循环/无用/在用），颜色区分状态<br>3. **合并视图**：依赖图、循环依赖、无用组件、扇入扇出、越层、未解析信息整合到一个页面（dagre 图 + 底部可切换列表栏），不再需要多个 tab 切换<br>4. **入口识别增强**：自动扫描 router 目录的懒加载页面作为入口，修正真实项目误判无用组件的问题（示例项目从 29 个误判降至 10 个）<br>5. **MCP server**：新增 `@shaohui_jin/comp-insight-mcp-server`，支持 stdio 工具 + HTTP UI 页面（与扩展面板同款 UI）<br>6. **Skill 注入**：安装扩展即注册 `/comp-vue-insight`，并同步到全局 skills 目录<br>7. **全量侧重图**：dagre 分层整体俯瞰，节点大小 ∝ 扇出，可导出 PNG<br>8. **包自包含**：VSIX 内联 `@vue/compiler-sfc` 与 core 引擎，安装后无需额外依赖 |
